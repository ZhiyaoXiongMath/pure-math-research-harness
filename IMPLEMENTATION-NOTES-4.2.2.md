Internal native delegates are outside the root gate and stage pool. SURVEY remains host-controlled and serial.

Final scientific capture admission still requires the sealed window. Exact actually delivered source references, pending human directions and MAIN's own responsibility bindings remain distinct from invented observations.

Communication permission, actual exposure and scientific use are separate facts. Status transport and bounded control-only rejection remain possible during pause without admitting scientific dispatch. Source versions, native Arguments, scoped support and independent-review eligibility remain mandatory; implementation repairs do not confer proof qualifications.

## Recovery and input growth repairs

- Context reference sets are normalized after local aliases resolve, without reordering argument steps or changing scientific prose. Original rejected responses remain preserved for normal re-admission.
- MAIN progress accounting recognizes only exact confirmed live-dispatch receipts from the same request/execution. It does not silently refresh the original frontier or treat an assignment acknowledgement as scientific evidence.
- MAIN history navigation avoids repeated request/usage ledgers. Versioned reversible metadata tables and packed shared values preserve the decoded packet and prior frozen input representations.
- Candidate22 supplies the complete method, original target/scope sources, guidance, checkpoint and incremental metadata up front. Every historical material remains available as an exact frozen original; MAIN selects additional reads and must obtain complete relevant premises, failures, scope and qualification evidence before relying on a claim. Availability is not a reading claim or a simultaneous lifetime preload.
- Startup capacity checks retain output reserve and stage rules. Conservative encoded-byte bounds do not claim exact tokenizer or lifetime-session capacity. Arbitrary future input growth is not proven safe.
- A narrow maintenance path preserves a captured launcher failure, its original usage and rejection, and binds an explicitly authorized successor to the same Goal after native runtime repair. It grants no budget and does not itself resume a pause.
