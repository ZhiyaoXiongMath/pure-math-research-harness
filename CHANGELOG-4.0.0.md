# PMRS 4.0.0

Initial release in a new private repository with fresh Git history, based on the reviewed current native product snapshot.

- Removed all old source trees, project upgrades, format readers, compatibility adapters and imported proof-authority paths.
- Removed concrete research datasets, archive fixtures, conversion reports and continuation release packages.
- Retained TRW/TFDW, complete workflow maps, exact model/reasoning policy, native knowledge/materials/history, budget and task control, UNKNOWN disposition, idempotency and restart recovery.
- Retained native backup/restore with explicit rejection of unsupported inputs, without rewriting the native storage format merely to break compatibility.
- Isolated 4.0 default workspaces, settings and browser storage; versioned menu entries and a distinct Debian installer package preserve existing installations.
- Retained reports, settings and official client login integration. Replaced migration fixtures with synthetic native tests and rebuilt the acceptance inventory for the authorized 4.0 scope.

See [actual validation](TEST-REPORT-4.0.0.md), [scope](ACCEPTANCE-SCOPE-4.0.0.md) and [installation](UBUNTU-E2E-GUIDE.md). The release archive's BUILD-INFO.json and Release SHA256SUMS.txt bind final code and artifacts.
