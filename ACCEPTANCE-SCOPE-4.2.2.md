# PMRS 4.2.2 acceptance boundary

Candidate22 has build and isolated-installation evidence and limited runtime evidence from one real HSC eigenvalue TRH experiment. That experiment used its original cumulative 300 PMRS top-level call allowance through legitimate repairs and continuation. It remains OPEN and was subsequently paused by user instruction, including its native Goal.

Building, correct startup refusal, an accepted model response, nonzero usage and a saved progress report are not full acceptance. Stage delivery, user ending, pause and budget exhaustion must not be recorded as successful Goal completion. Source and support qualification, exact target scope and independent reviews remain authoritative.

For this code-only publication, preserve all private original requests, materials, outputs, errors and usage locally. Publish only sanitized implementation/status summaries. No new research call, simulated scenario, stress run, independent paid probe, FDH/SURVEY acceptance or test matrix is authorized. Existing tests and fixtures remain source resources; no new pass is inferred from their presence.

The unexercised boundaries include FDH D5/adoption/handoff, SURVEY paid operation, exhaustive manual P14 and communications, multi-project saturation, timer/recovery edge cases, arbitrary input scale and complete mathematical qualification. See [the validation report](TEST-REPORT-4.2.2.md) for the precise limitations. No tag or GitHub Release is part of this push.
