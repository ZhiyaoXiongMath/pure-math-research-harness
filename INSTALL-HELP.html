Install Pure Math Research Studio 4.2.2

Development candidate: use an independent empty workspace. Candidate22 has limited real TRH runtime evidence; HSC remains OPEN and was subsequently paused by the user. This is not complete acceptance. These steps apply when matching verified candidate artifacts are available and do not declare a public Release.

Target: Ubuntu 26.04, Python 3.11+. Ordinary installation, setup and research controls are available through the graphical interface.

  1. Verify SHA256SUMS.txt, then open pmrs4-graphical-installer_4.2.2_all.deb with Ubuntu’s graphical package installer. System authorization may be requested. Python venv and Zenity dependencies come from Ubuntu repositories.
  2. From Applications, open Install Pure Math Research Studio 4.2.2. Select a new personal installation location. PMRS and its wheel are included for offline installation; obtaining missing system packages needs network access.
  3. Open Pure Math Research Studio 4.2.2 from Applications. In Settings & sign-in, choose existing Codex CLI, Tectonic, offline-resource or public-CA paths, or explicitly install the listed official components.
  4. Use the official Codex client’s login. PMRS does not receive account passwords. Installation and setup do not start research model calls; research requires your separate start and bounded authorization.

English is the default interface. Use Language to choose English or 简体中文. The preference is saved on the host and applies to application-owned native prompts. Research bodies and formal reports remain English.

Without PDF components you can browse and do work that does not require PDF output. Report generation separately checks the compiler, offline resources, fonts and isolation; a detected tool is not evidence of a successful compilation.

If a desktop file opens as text

A .desktop file describes a launcher, and some file managers open it in an editor. Use the .deb package and Applications-menu route above. An administrator can also verify and extract a release ZIP with the included prepare-release.py to register its installer entry.

If the desktop has no graphical handler for local Debian packages, install an appropriate package installer through Ubuntu’s Software Center, then reopen the .deb. If Zenity or Python venv is absent, open these packages in the Software Center or search for their names there. Existing installation targets and projects are not overwritten by a retry.

See English usage guide and installation acceptance steps. Native desktop clicks must be observed on the actual target desktop.

安装纯数学研究工作室 4.2.2

开发候选：请使用独立空工作区。candidate22 已有有限真实 TRH 运行证据；HSC 仍为 OPEN，后续已按用户要求暂停，不代表完整验收。以下步骤适用于同批已核验候选产物实际可用后，不宣称已公开发布。

目标环境：Ubuntu 26.04，Python 3.11+。日常安装、配置和研究操作均可通过图形界面完成。

  1. 核对 SHA256SUMS.txt，用 Ubuntu 图形软件包安装器打开 pmrs4-graphical-installer_4.2.2_all.deb。系统可能请求管理员授权，Python venv 与 Zenity 依赖由 Ubuntu 软件源提供。
  2. 从应用菜单打开 “安装纯数学研究工作室 4.2.2”，选择新的个人安装位置。PMRS 与 wheel 已打包，可以离线安装；获取缺少的系统组件需要网络。
  3. 从应用菜单打开 “纯数学研究工作室 4.2.2”。在“设置与登录”中选择已有 Codex CLI、Tectonic、离线资源或公共 CA 路径，也可明确安装界面列出的官方组件。
  4. 使用官方 Codex 客户端登录。PMRS 不接收账号密码；安装和配置不会调用研究模型，研究需要你另外启动并给出有限授权。

默认界面为英文，通过 Language／界面语言 选择 English 或简体中文。偏好由宿主保存，也用于应用自己的原生提示；研究正文与正式报告保持英文。

缺少 PDF 组件仍可浏览和开展不需要 PDF 的工作。生成报告时另行检查编译器、离线资源、字体与隔离；检测到工具不等于已成功编译。

如果桌面文件打开成文本

.desktop 是启动器说明，一些文件管理器会用文本编辑器打开它。请使用上述 .deb 安装包与应用菜单入口。管理员也可用随包 prepare-release.py 验证并解压 release ZIP，再注册安装器菜单。

若桌面未关联本地 Debian 包的图形安装器，可从 Ubuntu 软件中心安装合适的程序后重开 .deb。若缺少 Zenity 或 Python venv，可在软件中心打开这些组件，或直接搜索名称安装。安装器重试不会覆盖已有安装目标与项目。

详见中文使用说明与安装验收步骤；原生桌面点击须在实际目标桌面上观察。
