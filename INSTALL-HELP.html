安装纯数学研究工作室 4.0.0

适用环境：Ubuntu 26.04。普通安装、配置与研究操作均可通过图形界面完成，无需终端、环境变量或手写配置文件。

  1. 打开交付目录中的 pmrs4-graphical-installer_4.0.0_all.deb，选择 Ubuntu 的图形软件包安装器。系统可能请求管理员授权；依赖 Python、venv 与 Zenity 由系统软件源处理。
  2. 完成后，从 Ubuntu 应用菜单打开 “安装纯数学研究工作室 4.0.0”，选择个人安装位置。PMRS 本体及其 wheel 已包含在安装包中，可离线安装；下载缺少的系统组件需要网络。
  3. 安装完成后，从应用菜单打开 “纯数学研究工作室 4.0.0”。在网页“设置”中选择现有 Codex CLI、Tectonic、离线资源目录或公共 CA 文件，也可明确点击安装固定官方版本及准备离线 TeX 资源。
  4. 通过官方 Codex 登录窗口登录。PMRS 不接收密码；安装和检查不会自动启动付费研究。只有明确启动研究后才可能调用模型。

缺少 PDF 组件时仍可浏览与进行不需要 PDF 的工作；生成报告前会单独检查编译器、资源、字体和隔离环境。工具存在不代表报告已经通过实际编译。

如果打开的是文本编辑器

.desktop 是启动器描述文件。某些文件管理器会将 ZIP 中的此文件当成文本，且解压工具可能未恢复执行权限。请优先使用同目录中的 .deb 图形安装包并从应用菜单启动，而不是继续编辑该文本文件。管理员预备好的 ZIP 交付也可通过附带的 prepare-release.py 验证解包并注册应用菜单；该步骤属于交付准备。

若系统没有关联 .deb 的图形安装器，请从 Ubuntu 应用中心安装支持本地 Debian 软件包的图形软件包安装器，再重新打开 .deb 文件。系统桌面点击是否可用仍以这台机器上的实际点击结果为准。

缺少图形选择器

在软件中心安装 Zenity 和 Python venv。若该链接未打开，请直接在 Ubuntu 应用中心搜索这些名称；安装后重开安装器或网页。已有研究项目不会因安装器重试而被覆盖。

Ubuntu 26.04: open the bundled .deb with the graphical package installer, then launch Install Pure Math Research Studio 4.0.0 from Applications. The PMRS wheel is bundled for offline installation. In the web Settings page, select local dependency paths or explicitly install pinned official components. Official Codex login handles credentials. PDF dependencies only gate PDF operations; installation never starts paid research. If a desktop file opens as text, use the package/application-menu entry. Native desktop clicks still require verification on the target desktop.
