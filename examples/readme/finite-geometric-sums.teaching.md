# Synthetic teaching material: finite geometric sums

This material was written for the PMRS usage example. It is not a publication,
retrieved literature, or an independently checked mathematical record.

Let n be a positive integer and q a real number. Define
G_n(q) = 1 + q + ... + q^(n-1).

For q != 1, multiply the finite sum by q and subtract:
(1-q)G_n(q) = 1-q^n, so G_n(q) = (1-q^n)/(1-q).
For q = 1, each term is 1 and G_n(1) = n. Do not divide by 1-q here.
For n = 1, G_1(q) = 1 in both cases.

The scope is finite sums only. This material makes no claim about infinite
series, convergence, matrices, or historical priority.
